# Takt UI prototype

**Selected design: Apricot**, chosen October 3, 2026. This is the only active UI prototype and the basis for further design refinement.

Open [index.html](index.html) directly in a browser. No installation, build, server, remote fonts, or JavaScript is required.

The header combines the Takt logo, an editable file-name specimen, undo/redo, zoom, and Weeks / Dates. The file-name specimen is not part of the first implementation milestone. The previous hero copy and redundant “7 DAYS” labels are removed. Section headings have no vertical divider; the table header and row-label dividers retain the shared label-column boundary. Year labels appear only in Dates mode.

The file name is centered in the header, with no separator beside the logo. It uses a white input surface with its edit icon inside the field. Focus applies one Apricot border. Selected bars use one border in their own section color, directly against the fill, with no offset outline or gap.

The Apricot, lavender, and sea-blue palette, refined Swiss Grid typography, 44 px rows, bar styling, and component studies are preserved. Example / New document and Weeks / Dates work through HTML and CSS. File-name edits last for the current page session; chart gestures, zoom, menus, undo/redo, and the remaining editing commands are visual samples.

Edit `index.html` and `styles.css` directly. This prototype is a visual reference, not production app code. The [functional UX specification](../docs/ux-specification.md) remains the source for app behavior.

All previous directions, palette comparisons, research, and generators are preserved in [archive/ui-prototypes](../archive/ui-prototypes/README.md). The archived generators are historical authoring tools; they do not generate this selected prototype.
