## Reconciliation changes

The control refinement adds six-dot row/section handles, automatic Dates mode on every applied reference, the simplified calendar, and the shared continuous hue color picker. `tests/components/structure.spec.ts` verifies both handles and click behavior, with real row-handle transitions in `structure-motion.spec.ts`. `date-menus.spec.ts` covers setup/reset from headings and the toolbar, cancellation and atomic display/reference undo. `color-picker.spec.ts` covers sections, bars and milestones, retained targets, draft previews, inheritance, undo/redo, keyboard navigation, focus containment and dismissal preserving redo. `src/model/calendar-colors.test.ts` exercises preset and fractional hues through validation, inheritance, movement and history. Production color coverage opens the picker; visual baselines cover both color drafts, the simplified calendar, handles and revised quick palettes. Supported-year limits remain covered in `src/components/calendar-grid.test.ts`.

Calendar-reference menus on timeline headings and the Dates toolbar button are covered by `tests/components/date-menus.spec.ts` in all three browsers: reference setup and replacement at the captured week, draft cancellation, clearing and atomic undo/redo, Week 1 from Dates, focus restoration, and native browser menus outside chart targets and the Dates button. `tests/e2e/calendar-colors.spec.ts` verifies clearing and restoration in the production editor; `tests/visual/states.spec.ts` covers Set reference, Reset/Clear reference from Dates, and the keyboard highlight using the shared Apricot menu.

The context-menu refinement retains existing commands. `tests/components/colors-menus.spec.ts` checks measured placement at the right and bottom edges, keyboard focus across grouped actions and swatches, neutral mouse opening, and one shared highlight during pointer/keyboard handoff. `tests/visual/states.spec.ts` covers the target headings, icons, palette, separators and destructive actions for all five menu targets, plus the shared deletion buttons.

The custom-control refinement adds `tests/components/custom-controls.spec.ts` for the zoom listbox, keyboard and outside dismissal, intermediate wheel values, centered calendar backdrop, focus containment, date drafts, leap-day/month navigation, Today and chevron motion. `src/components/calendar-grid.test.ts` verifies grid arithmetic and invalid dates. Visual baselines include the open zoom menu, selected calendar draft, full date dialog and shared confirmation buttons.

History reveal previously looked only for the primary object in the resulting document. Undoing creation removed that object; redoing deletion did too. The document changed correctly, but a collapsed section could stay closed and an off-screen result stay invisible. `src/viewport.ts` now derives the affected location from the command snapshots when the object no longer exists, while only selecting objects that still exist. Container removal reveals the surviving parent or neighboring section; removal of the final section reveals the empty chart. These view adjustments stay outside history.

The reconciliation adds deterministic location rules, three-browser behavioral and motion regressions, and a production scenario for initial state, negative weeks, mixed deletion/hint recovery, and refresh/recovery. Existing visual baselines remain unchanged because the corrected reveal uses the existing expansion and layout styles.

`AGENTS.md` already matches the root npm commands, specification routing, and automated acceptance contract; no additional guide rules or dependencies are needed.

Window layout and overview navigation are covered by `tests/components/viewport-layout.spec.ts` in all three browsers: frozen top/left context during two-axis scrolling, responsive chart sizing, weekly creation at 12.5% followed by zoom for readable naming and resize targets, adaptive calendar bands, spaced week labels, and reference targeting at overview scale. `src/timeline-headings.test.ts` verifies actual month/year boundaries, leap days and week-label density. Visual baselines cover frozen headings and overview scales.

`tests/components/grid-alignment.spec.ts` samples actual painted lane pixels at fractional and preset zooms in all three browsers and compares grid lines with individual header boundaries. It prevents stretched weeks, missing lines and header/lane drift. `viewport-layout.spec.ts` verifies the recalibrated 24/12/192-week scales. `ShortBars` exposes separated and adjacent one-week bars and mixed durations. `overview-motion.spec.ts` advances the real zoom animation through intermediate frames, checks pointer anchoring and pinned labels, verifies naming focus and full-bar visibility, and covers Escape, wheel and blur interruption without document/history changes. Visual baselines cover compact bars and zoomed naming.

The continuous color refinement fixes OKLCH lightness and chroma across all hues. `src/model/palette.test.ts` verifies full-circle perceptual consistency, sRGB conversion, readable labels and invalid hue rejection. `tests/components/color-picker.spec.ts` covers pointer dragging, keyboard endpoints and steps, exact non-preset reopening, centered plus geometry, draft cancellation, inheritance and atomic history in all supported browsers. Color picker and context-menu screenshot baselines cover the date-inspired overlay and removal of the current color name.

The timeline refinement starts visible weeks, months and years at one while retaining zero-based document coordinates. `src/model/calendar-colors.test.ts` checks origin and timing labels; `src/timeline-headings.test.ts` checks relative calendar-length months, leap years and continuous boundaries across zero and negative years. `viewport-layout.spec.ts` checks the upper year tier in both modes at every zoom, matching month thresholds, and pointer/keyboard reference targeting without a real calendar reference. `color-picker.spec.ts` checks reuse and deduplication of applied hues across sections, bars and milestones, excluding cancelled drafts; rule coverage checks the used palette through undo/redo. `drag-edit-regressions.spec.ts` checks a single shadow at the complete carried section's bottom, with no heading or interior row shadows. Visual baselines cover detail and overview headers, wrapped used-color swatches and carried sections; existing structural motion coverage continues to verify attachment and settlement.
